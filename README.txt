Poker Advisor - installable web app

Upload ALL of these files (not the folder) to a GitHub repository and turn on GitHub Pages:
  index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png

Then open https://YOUR-USERNAME.github.io/REPO-NAME/ in Chrome on the phone and tap Install app.
After the first visit it works offline.
